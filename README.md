# 우리동네 운동모임 - 주짓수 초보자 모임

주짓수 초보자들을 위한 동네 운동 커뮤니티 소개 랜딩 페이지입니다. 모임 소개, 운동 일정, 참여 안내, 회원 후기, 가입 신청 폼 등을 포함한 반응형 웹사이트입니다.

> 📌 포트폴리오 데모입니다. 실제 서비스가 아니며, 가입 신청 폼은 실제로 데이터를 전송하지 않고 클라이언트 사이드에서만 동작합니다.

## 주요 기능

- 스크롤에 반응하는 헤더 스타일 변화
- 퀵 메뉴 스크롤 스파이 및 부드러운 스크롤 이동
- 운동 일정 탭 전환
- 참여 안내 아코디언
- 회원 후기 자동 슬라이드 캐러셀
- 가입 신청 폼 유효성 검사
- 하단 고정 가입 문의 바
- Intersection Observer 기반 페이드인 애니메이션

## 기술 스택

순수 HTML / CSS / JavaScript (별도 프레임워크나 백엔드 없음)

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.
